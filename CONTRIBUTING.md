# Contributing Guidelines

Thank you for your interest in improving Image Compressor App.

## How to Contribute

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/image-compressor-app.git
   ```
3. Create a descriptive branch for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Test your changes locally to ensure the server starts and compression works as expected.
5. Commit your work with clear commit messages.
6. Push to your branch and submit a pull request.

## Reporting Issues

If you find a bug or have an idea for an enhancement, please create a new issue detailing:
- Steps to reproduce (if reporting a bug)
- Expected vs actual result
- Environment details (browser, Node.js version)
